# Algoritmos: paralelismo, voraces, búsqueda local y metaheurísticas (TSP)

Estructura:
```
main.py            # los 5 ejercicios en un solo archivo
requirements.txt
results/           # resultados (json/csv) y results/figures/ (gráficas)
report/reporte.md  # reporte final
```
Uso:
```
pip install -r requirements.txt
python main.py        # ejecuta los 5 ejercicios
python main.py 3 5    # solo los ejercicios indicados
```
